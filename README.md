# Pixel Guesser

A fixed-list Minecraft item guessing game for the web.

## Play

Open `index.html` in a browser, or enable GitHub Pages for this repository.

- The item begins with one revealed 16×16 texture pixel.
- Each incorrect guess removes one heart.
- Revealing another pixel removes one heart.
- You have 32 hearts.
- The full item is shown after a correct guess or at game over.

No build step or dependencies are required.
